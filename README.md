# Lisan-Al-Gaib

> "The one who can see the path." —— 每周更新的 AI / Agent 工程实践小工具集。

本仓库的内容**不是转载**：每周针对近期 AI / Agent 开源生态中真实出现的问题与需求（框架缺陷、工程化痛点、尚无好方案的空白），进行独立分析并实现一个可以直接运行的小工具。

## 结构

```
tools/
  YYYY-MM-DD-<slug>/   # 每期一个小工具目录
    README.md          # 问题背景 / 现有方案不足 / 本工具方案与用法
    ...                # 核心代码与示例
topics.md              # 已发布主题台账（自动更新，防止重复选题）
```

## 更新节奏

每周一期，由自动化流程完成：选题 → 独立分析 → 实现工具 → 提交到本仓库。

## 原则

- 所有代码与论述均为原创，参考他人方案时在对应 README 中注明来源链接；
- 依赖尽量少，拿到即可运行；
- 质量优先于规模。
