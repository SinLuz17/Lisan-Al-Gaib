# Lisan-Al-Gaib

> "The one who can see the path."

AI / Agent 工程实践里的一个小工具铺子。不是转载，也不是教程：每个工具都从开源生态里实际发生的问题长出来——框架缺陷、工程化痛点、还没人给出好方案的空白——先分析清楚，再写成一个拿到就能跑的东西。

想到值得深挖的问题就做一个，不排期。

## 结构

```
tools/
  YYYY-MM-DD-<slug>/   # 一个工具一个目录
    README.md          # 问题背景 / 现有方案不足 / 方案与用法
    ...                # 核心代码与示例
topics.md              # 做过的题目，自己查重用
```

## 原则

- 代码与论述均为原创；参考他人方案时，在对应 README 里注明来源链接；
- 依赖尽量少，拿到即可运行；
- 质量优先于规模，宁可小而完整。
